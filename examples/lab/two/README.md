# Lab TWO chapters

The two-qubit examples follow four separate teaching chapters:

1. [Principles of Quantum Computing](principles): signals, Rabi, T1/T2, control, initialization and reconstruction.
2. [Quantum Algorithms](algorithms): eight built-in algorithm examples.
3. [Integrated Quantum Technology Experiments](technology): spin echo, decoupling and pulse design.
4. [Research Experiments](research): physical-layer and circuit-layer definitions.

Each source has `build_parameters()` and `run_experiment()`. Edit calibrated settings, then run the file from your IDE or import the function. The default configuration file is `connection_config.local.json` in your working directory. A direct run connects to hardware.

Offline validation and result persistence are demonstrated separately in [advanced examples](../../advanced). Code explanations are in English; the manuals provide corresponding Chinese and English pages.
