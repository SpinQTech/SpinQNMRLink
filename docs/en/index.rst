SpinQNMRLink developer manual
==========================================================

One Python SDK for **Lab** and **Triangulum**, with explicit device sessions and a complete experiment catalogue.

Start with :doc:`installation` and the offline check in :doc:`quickstart`.
For a hardware run, prepare a reachable device service, credentials and
sample-calibrated parameters using :doc:`configuration`. Check :doc:`validation`
for the distinction between offline checks and recorded hardware measurements.
Contribution, support, security reporting and license information are in
:doc:`community`.
