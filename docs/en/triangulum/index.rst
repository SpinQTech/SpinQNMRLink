Triangulum experiments
============================================

.. important::

   Before connecting to a Triangulum device through the SDK, open the Triangulum
   client software and create a user account and password in **User Center (用户中心)**.
   Use those credentials for ``account`` and ``password`` in the connection
   configuration, or for the corresponding credential environment variables.
   Without a registered account and matching credentials, you cannot log in
   or use the device. See :doc:`../configuration` for configuration steps.

Physical-layer experiments (``triangulum.physical``) require **Triangulum client software version 1.6.1 or later**.
Check the client version before running; see :doc:`physical`.
