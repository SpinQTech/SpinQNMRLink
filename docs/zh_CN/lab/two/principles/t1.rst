T1 纵向弛豫
==============

运行带等待区间的 T1 参考点。

设备：**lab**，模式：**TWO**。运行前准备样品与校准后的脉冲、频率参数。

在 IDE 中打开下方源码，先修改 ``build_parameters()`` 中的校准参数，再直接运行文件或调用函数。配置路径相对于当前工作目录。离线检查、保存与评估见 :doc:`/advanced`。

.. code-block:: python

   from examples.lab.two.principles.t1 import build_parameters, run_experiment

   parameters = build_parameters()
   result = run_experiment("connection_config.local.json", parameters=parameters, timeout=300)
   print(result.data)

输出解读
--------

以下使用占位符解释输出格式，不是硬件测量数据：

.. code-block:: text

   Task: COMPLETED <task-id-or-None>
   Measured amplitude: <device-amplitude>
   Pulse-width result: <reported-width-or-None>

幅度是设备测量信号，不是归一化概率。单点不能估计 Rabi 周期或 T1/T2 寿命，应使用原理章的完整扫描。
