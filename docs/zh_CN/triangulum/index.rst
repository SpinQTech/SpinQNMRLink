Triangulum 实验
==========================

.. important::

   使用 SDK 连接三角座设备前，必须先在 **三角座客户端软件的用户中心**
   创建用户账号和密码。将创建的账号和密码用于连接配置中的 ``account``
   和 ``password``，或相应的凭据环境变量。
   未创建账号或凭据不匹配时，无法正常登录和使用设备。
   配置步骤见 :doc:`../configuration`。

物理层实验（``triangulum.physical``）要求 **三角座客户端软件 1.6.1 及以上版本**。
运行前先确认客户端版本，详细要求见 :doc:`physical`。
