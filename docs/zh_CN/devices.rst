设备与平台支持
==============

公开设备名称为 ``Lab`` 和 ``Triangulum``，每个 SDK 可同时管理各一个实例。设备连接、任务和故障相互独立，不自动切换设备。

Lab 使用 TCP 或二进制 WebSocket，支持 TWO 和 THREE 模式，由服务端确认模式与设备状态。两比特示例和文档分为四章，三比特单独组织。

Triangulum 由 Python 直接实现 JSON 文本 WebSocket，负责认证、应用层心跳、提交确认和结果关联。其就绪状态表示连接且认证成功，不包含 Lab 式的设备状态快照同步。连接异常时关闭会话，尚未明确结束的任务报告结果未知；重新连接必须显式调用，实验不会自动重发。消息与结果详见 :doc:`protocols/triangulum_protocol`。

跨平台设计
----------

Windows、Linux 和 macOS 使用相同的公开 API、Conda 源码安装流程及 Python 示例。两类设备均通过网络访问可达的设备服务，无需 SDK 自带的设备原生库。构造与参数验证不启动连接。``open()`` 建立会话，``close()`` 释放 socket 和接收线程，不取消远端实验。

发行包为 ``py3-none-any`` wheel，表示 SDK 本身为纯 Python 包，不代表每种依赖在所有平台均可用。核心检查无需 GUI；绘图和 Qt 可选依赖的平台条件单独考虑。客户端操作系统不改变设备服务、固件或支持的实验模式。
