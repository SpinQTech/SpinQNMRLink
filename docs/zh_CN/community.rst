贡献、支持与许可证
==================

参与贡献
--------

:download:`贡献指南 <../../CONTRIBUTING.md>` 统一维护贡献流程、本地检查及
PR 要求。新增实验或适配器时，同时阅读 :doc:`development`。
中英文页面及对应 Python 示例须同步更新。

使用支持与缺陷报告
------------------

先查阅 :doc:`troubleshooting`、:doc:`devices` 与 :doc:`validation`。
:download:`支持指南 <../../SUPPORT.md>` 说明如何通过源码仓库的问题跟踪器
报告 SDK 问题。按 :download:`缺陷报告模板 <../../.github/ISSUE_TEMPLATE/bug_report.md>`
提供 SDK/Python 版本、操作系统、最小复现和脱敏日志。
设备相关问题另附设备类型、固件版本和实验键。
设备服务与校准问题应联系设备支持方。

安全问题报告
------------

疑似漏洞按 :download:`安全报告指南 <../../SECURITY.md>` 处理。
优先使用仓库的私密报告入口；未开启时，使用已有的维护者私密联系方式。
请勿在公开问题中提交凭据、完整会话 ID 或敏感通信报文。

许可证与版本记录
----------------

Python 源码采用 GPL-3.0-only，完整条款见
:download:`LICENSE.txt <../../LICENSE.txt>`。
版本变化由 :download:`CHANGELOG.md <../../CHANGELOG.md>` 统一维护。
设备与平台的实际验证证据另见 :doc:`validation`。
