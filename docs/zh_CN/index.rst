SpinQNMRLink 开发文档
==================================

面向 **Lab**、**Triangulum** 的统一 Python SDK，提供独立设备会话与完整实验目录。

首次使用先阅读 :doc:`installation`，再执行 :doc:`quickstart` 中的离线检查。
真实设备运行需要可访问的设备服务、凭据和样品校准参数，准备步骤见
:doc:`configuration`。离线检查与已记录的设备测量分别见 :doc:`validation`。
贡献、支持、安全报告与许可证入口见 :doc:`community`。
