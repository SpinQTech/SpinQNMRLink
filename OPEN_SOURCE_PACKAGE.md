# SpinQNMRLink 1.0.0 source snapshot / 开源源码包

Start with [README.md](README.md) or [中文说明](README.zh_CN.md).
Install from this directory with `python -m pip install -e .`.
Development/docs: `python -m pip install -e ".[dev,docs]"`.
License: [GPL-3.0-only](LICENSE.txt).

**Density-matrix support requires Triangulum client 2.0 or newer.**
**密度矩阵功能需要三角座客户端 2.0 及以上版本。**

This snapshot includes the SDK, examples, offline tests, bilingual source manuals,
packaging tools and public GitHub workflow/templates. It contains no Git history,
private connection profiles, raw measurements, internal reports or build caches.
`.github/` and `.gitignore` are public project configuration, not repository history.
Current evidence and its limits: [verification](docs/release-verification-20261027.md).

本包包含 SDK、示例、离线测试、双语文档源码、打包工具和公开工作流及模板。
不含 Git 历史、本地连接配置、原始实测资料、内部报告和缓存。
本次开始通知兼容修复已经离线验证；未重跑客户端采集。详细范围见验证说明。
